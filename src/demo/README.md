# Conteúdo demonstrativo

Este diretório concentra textos, catálogos, opções e exemplos fictícios da V0. Nada aqui foi validado para uso clínico ou produção. Componentes e casos de uso referenciam estas definições para impedir que conteúdo provisório seja confundido com regra de domínio.

- `consent.ts`: termo provisório e versão persistida.
- `anamnesis.ts`: catálogo pequeno e versionado de perguntas demonstrativas.

Alterações nesses conteúdos exigem nova versão; não reutilize uma versão para significado diferente.
